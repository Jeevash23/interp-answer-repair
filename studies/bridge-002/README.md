# Grammatical wording and group blocking

Tests behavioral recovery on solved grammatical wording, order/role controls and downstream group blocking.

This is an experimental component of the [activation-transfer project](../../README.md). Its full methods and findings are in the [manuscript](../../paper/manuscript.pdf). The recorded experiment identifier is Bridge 002.

Use the root environment and [replay instructions](../../REPRODUCIBILITY.md). Protocols, amendments, numerical results and original source snapshots remain in this directory. [Component results](RESULTS.md) provide the detailed numerical record.
