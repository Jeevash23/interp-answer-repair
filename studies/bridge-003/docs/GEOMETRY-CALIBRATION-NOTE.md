# Post-selection geometry calibration

Added after inspecting Medium's completed wording-transfer measurements, while
the remaining intervention conditions were running. This is a post hoc diagnostic;
it does not change the frozen selection, analyzer, thresholds or primary outcomes.

Apply the existing geometry metric to two saved clean signatures: the unchanged
recipient (zero displacement) and the actual matched clean donor (a reference
endpoint). Check the same S, off-axis and donor-proximity conditions. This tests
whether the operational criterion recognizes its intended clean-donor endpoint
on held-out data. It is not a new model intervention or a demonstrated compact
router. The actual donor runs on different wording and is therefore a geometric
calibration, not the result of activation transfer into a fixed recipient.

Retain any calibration failure. Report the S intervals with the original
eight-quantity adjustment only to make the threshold comparison consistent;
this diagnostic was not part of the original primary test family. Separately
report the behavior and separability gates, which can invalidate a model-level
switch claim even if the metric recognizes its reference endpoint.

The first Medium check failed the off-axis condition in every cell/reference:
the true donor's mean S was 1.04–1.22, but its off-axis magnitude was 1.17–1.49.
Thus the frozen strict gate is too restrictive to recognize this endpoint. Keep
its output as an operational result, but do not interpret its failure as evidence
that no full mechanism transfer occurred. This is an assay limitation.

As a second explicitly post hoc descriptive diagnostic, project the edited
signature onto each actual recipient-to-donor difference instead of the discovery
centroid axis. This paired axis has exact reference endpoints S=0 and S=1, with
zero off-axis remainder at either endpoint. Report intervals and distances without
declaring a new replacement primary switch rule. The per-example axis uses held-out
clean references, so it is not the original discovery-fixed geometry; no edit or
family is selected using it. Its purpose is to expose sensitivity to reference
geometry and interpret the already-prespecified actual-donor proximity measure.
