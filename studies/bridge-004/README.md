# Paired endpoint comparisons

Tests paired downstream geometry in fresh Medium and TinyLlama cohorts, retaining separation failures and the documented analysis correction.

This is an experimental component of the [activation-transfer project](../../README.md). Its full methods and findings are in the [manuscript](../../paper/manuscript.pdf). The recorded experiment identifier is Bridge 004.

Use the root environment and [replay instructions](../../REPRODUCIBILITY.md). Protocols, amendments, numerical results and original source snapshots remain in this directory. [Component results](RESULTS.md) provide the detailed numerical record.
