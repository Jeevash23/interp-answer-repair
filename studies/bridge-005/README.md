# Independently qualified replication

Tests a prospectively specified GPT-2 Medium comparison with disjoint fitting, selection, qualification and final-test banks.

This is an experimental component of the [activation-transfer project](../../README.md). Its full methods and findings are in the [manuscript](../../paper/manuscript.pdf). The recorded experiment identifier is Bridge 005.

Use the root environment and [replay instructions](../../REPRODUCIBILITY.md). Protocols, amendments, numerical results and original source snapshots remain in this directory. [Component results](RESULTS.md) provide the detailed numerical record.
