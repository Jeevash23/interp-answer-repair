# Routing experiments

Dependency-prediction experiments R1–R2: exploratory assay construction and the controlled test of compact and full-vector edits.

This is an experimental component of the [activation-transfer project](../../README.md). Its methods and findings are included in the [complete manuscript](../../paper/manuscript.pdf), especially Appendix H.

Use the shared root environment and [replay instructions](../../REPRODUCIBILITY.md). Data, results, frozen protocols and scientific source remain here. Local dependency lock files preserve the original experiment record; they do not define another active environment.
