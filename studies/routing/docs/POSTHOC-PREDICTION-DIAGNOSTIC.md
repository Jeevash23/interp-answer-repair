# Descriptive prediction comparison

This diagnostic was added after test behavior and the first compact-edit outputs were inspected.
It is **post hoc**, does not select a new site, and does not change any primary causal gate.

Compare the frozen internal predictor with a constant discovery mean and a discovery mean for
each known ABBA/BABA order. Every predictor uses only discovery-fitted numerical quantities;
the order baseline receives the input's known family label. All are scored against the same
continuous measured signature target on development and test sets.

This comparison prevents a predictable signal about word order from being presented as added
predictive information over a simple prompt variable. The result is descriptive and conditional
on the fixed family-axis target. The diagnostic, source and complete output are retained alongside
the main study, separately from its pre-test analysis freeze.
