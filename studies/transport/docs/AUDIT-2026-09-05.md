# Saved-output research audit — 5 September 2026

## Status and scope

This is a **post-hoc exploratory audit**, specified after the outcomes of Experiments
001–004 were available. It leaves their frozen implementation, protocols, results,
and original analyses unchanged. It is not a new confirmatory experiment and does
not replace the original declared tests. No model was loaded and no package or
system setting was changed. GPU access is not required to reproduce this audit.

The numerical results remain consistent with their saved records. Their strongest
defensible interpretation is **context-dependent, normalized endpoint recovery
under the specified intervention**. The saved evidence alone does not identify an
invariant directional mechanism, a particular mediating pathway, or general
superiority to a distribution of random circuits.

## 1. Integrity and reproduction

The audit freshly performed 97 SHA256 comparisons covering 86 distinct files:
effective source freezes, the two Experiment 004 amendment-chain links and amendment
scripts, selected pre-outcome results, and historical result/analysis hashes. All
97 comparisons match. The complete input inventory contains 118 SHA256 hashes,
including the audit script and the verifier source files from which literal
expected hashes were extracted. Verifier code was parsed without executing it.

All 19 retained Experiment 004 primary/reproduction scientific-file pairs are
byte-identical. These span feasibility, localization, development transport, and
test transport. Run configurations are excluded from byte equality because their
timestamps differ by design. Experiments 001–003 have no separate reproduction
directories in the current project: their current files match historical expected
hashes, but this audit cannot independently compare two retained model runs for
those studies. No model weights were rehashed and no model experiment was rerun.

The audit itself was run twice. Its two output files are byte-identical:

- `results/audit-2026-09-05/audit.json`
- `results/audit-2026-09-05/audit-reproduction.json`
- SHA256: `963101425f759467c4cb42a7557c0178e815443dfeb92531dcf03c5232b0736c`

The nine audit tests pass. They check donor mapping, the deterministic head rule,
paired identity alignment, missing/duplicate records, a constructed reversal
between raw and normalized direction, seeded bootstrap reproducibility, and
non-executing extraction of verifier constants.

## 2. The memory amendment changes control assignments

Experiment 004 transports in sorted-template batches and applies a two-row roll
**within each batch** to form the entity-mismatch control. Applying that exact rule
to the real frozen manifest gives:

| Split | Records | Donor changes, batch 20 → 4 | Changed random-direction batch-seed offsets |
|---|---:|---:|---:|
| Development | 160 | 80 (50%) | 128 (80%) |
| Test | 160 | 80 (50%) | 128 (80%) |

All new mismatch donors preserve ABBA/BABA pattern. In each split, 16/160 new donor
assignments share at least one name with the recipient's three-name tuple. This
does not mean those pairs have identical roles or that a mismatch control must
necessarily use disjoint names; it specifies exactly what the implemented control
did. Every recipient/donor mapping for batch sizes 20 and 4 is retained in the audit
JSON. Random-vector values were not reconstructed: only the seed-offset schedule
is audited, and tensor shape also changes with batching.

Amendment 002's historical statement that execution granularity alone changed is
therefore too strong. The documented rationale is a memory failure before any
transport outcomes were written. A pre-outcome amendment is legitimate, and this
finding is **not evidence of outcome-based tuning**. Nor does a changed donor
assignment establish that the reported scientific conclusion would change. The
correction is to acknowledge that the realized control assignment changed and
test robustness using per-example, batching-independent donor and random seeds.

## 3. The head comparator is deterministic

The function named `choose_random_heads` selects the first unused, nonselected head
after each selected head, cyclically within its layer. The script independently
reconstructs that rule; it exactly matches all eight stored condition/site
comparator groups across Experiments 002 and 004.

The accurate name is **deterministic cyclic layer-matched head comparator**.
Superiority to this one group remains an informative contrast. It does not by
itself estimate performance against a sampled distribution of random head groups.
The frozen machine-readable identifier `random_head` is preserved for provenance.
A future robustness experiment should draw several reproducible layer-matched
groups and keep head-group variability separate from prompt variability.

## 4. Raw and normalized directional effects answer different questions

For each direction, define the raw endpoint effect as the mean patched minus
corrupt target score. CTS divides this by that target condition's mean clean minus
corrupt score. The audit reconstructs both from per-example outputs. Forward
means canonical → controlled; reverse means controlled → canonical.

Intervals below use 5,000 hierarchical bootstrap resamples with seed 20260905:
resample eight held-out templates, then complete ABBA/BABA entity pairs within
each sampled template. Directions are aligned by exact example identity before
resampling. There are 80 paired entity triples per study. Intervals are **pointwise,
exploratory 95% percentile intervals**, with no multiplicity correction. They are
conditional on the frozen selected groups, models, prompts, and intervention dose;
selection uncertainty is not resampled. A new seed means these interval endpoints
need not equal the original frozen analysis endpoints.

### Primary probability-difference endpoint

| Study / site | Forward raw | Reverse raw | Raw forward − reverse [95% CI] | CTS forward − reverse [95% CI] |
|---|---:|---:|---:|---:|
| GPT-2 Medium / S2 | 0.0290 | 0.0361 | −0.0071 [−0.0339, 0.0247] | 0.1700 [0.0511, 0.2521] |
| GPT-2 Medium / END | 0.1222 | 0.1839 | −0.0617 [−0.1149, −0.0083] | 0.6414 [0.3114, 1.1432] |
| Pythia / S2 | 0.0490 | 0.0462 | 0.0028 [−0.0332, 0.0365] | 0.1332 [0.0337, 0.2313] |
| Pythia / END | 0.1281 | 0.0926 | 0.0355 [−0.0222, 0.0904] | 0.4696 [0.1958, 0.8414] |

For GPT-2 Medium, the forward and reverse clean-effect denominators are 0.1132 and
0.4193. At END, the forward effect is smaller in raw probability units yet larger
as a fraction of the target's clean effect. For Pythia those denominators are
0.1472 and 0.2312; its END raw directional interval includes zero. The replicated
positive probability-CTS contrast therefore does not establish replicated raw
forward-effect superiority.

### Secondary logit-difference endpoint

| Study / site | Raw forward − reverse [95% CI] | Logit-CTS forward − reverse [95% CI] |
|---|---:|---:|
| GPT-2 Medium / S2 | 0.1150 [−0.0663, 0.2753] | 0.1419 [0.0826, 0.1886] |
| GPT-2 Medium / END | 0.3567 [−0.3050, 1.0171] | 0.9312 [0.2998, 1.6892] |
| Pythia / S2 | −0.2021 [−0.3525, −0.0528] | 0.0187 [−0.0435, 0.1191] |
| Pythia / END | 0.0519 [−0.5039, 0.6768] | 0.4039 [−0.0553, 1.0562] |

The probability endpoint was the primary metric, so a secondary sensitivity does
not retroactively fail its original test. It limits stronger wording that would
imply endpoint-invariant asymmetry: Pythia's normalized logit-direction intervals
include zero. Probability difference is bounded and depends on the full output
distribution; it need not rank interventions exactly as logit difference does.

## 5. Direction also changes the selected group and injected signal

The forward experiment uses canonical-selected heads and the reverse experiment
uses controlled-selected heads. The eight-head groups overlap in 4 heads at S2
and 5 at END for GPT-2 Medium, and 6 at both sites for Pythia. None of the compared
forward/reverse groups is identical. In addition, source clean-minus-corrupt
activation magnitudes need not match. Thus the existing directional contrast
jointly changes source signal, selected group, target context, and denominator.

This is a valid operational comparison of the declared procedures. It does not
isolate which of those changes creates the asymmetry. A focused extension can hold
the group fixed across both directions, sweep or match dose, retain raw effects
alongside ratios, and repeat the comparison for both preselected groups. The
target condition's whole clean effect is not the same denominator as that target's
own selected-group patch effect; the JSON includes both within-condition group
effects for transparency and does not conflate them.

## 6. Local diagnostics and provenance constrain the claims

The historical S2 diagnostic projects changes in selected END-head outputs onto
their clean-minus-corrupt direction, normalized by that direction's squared norm
per example. It is a **normalized downstream alignment diagnostic**, not an
unnormalized probability numerator. Its failed sign criterion leaves the proposed
alignment unconfirmed; by itself it does not prove that all endpoint effects are
nonspecific.

The historical END diagnostic projects outputs of the actively patched head group
onto the IO-minus-subject unembedding direction. It omits the final normalization
and reads the patched group itself. A positive value is a local raw projection
diagnostic, not an independent demonstration of a mediating downstream pathway or
a normalized direct-logit contribution. Multiple additive head interventions can
also alter later selected heads through the intact network before their own deltas
are added. Those computations define the implemented intervention; positive
endpoint effects should not automatically be assigned to a unique path. These are
source-code observations, not quantities recoverable anew from cached activations
in this audit.

Local freeze records and their matching hashes provide useful internal provenance.
They are not independent proof of an external preregistration timestamp or of no
prior outcome access. At this audit snapshot the repository has zero Git commits.
The language **locally frozen pre-outcome protocol, according to the recorded
workflow** is justified more directly than **externally preregistered**. Historical
records must not be rewritten to manufacture stronger chronology. Starting a
versioned research record now can improve subsequent provenance.

The original charter also proposed clustering mechanism families and testing
whether transport predicts held-out faithfulness better than overlap or
representation similarity. These analyses are not supplied by the two-context
directional results. Either complete a separately specified benchmark or narrow
the paper's contribution and completion criteria explicitly.

## Reproduction

From the project directory, use the existing environment:

```sh
.venv/bin/python scripts/audit_research_20260905.py
.venv/bin/python scripts/audit_research_20260905.py --output results/audit-2026-09-05/audit-reproduction.json
cmp results/audit-2026-09-05/audit.json results/audit-2026-09-05/audit-reproduction.json
.venv/bin/pytest -q tests/test_audit_20260905.py
```

The script restricts outputs to the separate audit directory. The audit JSON
contains exact estimates, per-template statistics, both batch donor assignments,
retained-reproduction comparisons, effective freeze checks, and input hashes.
